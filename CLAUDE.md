# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this repository is

`mertinkito/mertinkito` is a GitHub **profile README** repository — a special repo GitHub recognizes by matching the repo name to the account username. Its `README.md` is rendered directly on the user's GitHub profile page (github.com/mertinkito).

There is no application code, build system, package manifest, or test suite in this repository. The entire content is the single `README.md` file.

## Working in this repository

- The only file that matters is `README.md`. Edits to it directly change what visitors see on the profile page.
- Keep changes to plain Markdown (GitHub Flavored Markdown), consistent with the existing short bio/emoji style.
- There are no commands to build, lint, or test — changes are verified by visual inspection of the rendered Markdown.
